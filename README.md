# IT4735 - IoT Application Labs

This repository collects short, hands-on IoT labs and examples intended for learning and classroom use. Each example is self-contained and demonstrates basic IoT concepts such as HTTP requests, MQTT messaging, AMQP, ESP32 device programming, and simple web APIs.

### Repository structure
- `ex1-http/`: simple HTTP example (ThinkSpeak integration example).
- `ex2-mqtt/`: MQTT lab with publisher/subscriber modules and helper utilities.
- `ex3-amqp/`: minimal AMQP example.
- `ex4-esp32-sensor-demo/`: ESP32 circuit and sensor demo (PlatformIO project).
- `ex5-esp32-http-request/`: ESP32 examples showing GET/POST (JSON and form) requests.
- `ex6-esp32-freertos-multitask/`: ESP32 FreeRTOS multitasking sample (PlatformIO project).
- `ex8-webapi/`: small web API example with OpenAPI and tests.

### How to use
- Open the lab folder you want to try and read its `README.md` for setup and usage notes.
- Most ESP32 examples are PlatformIO projects; run them with PlatformIO or the included instructions.

### Purpose
- This repo is for study and experimentation only — use the labs to learn common IoT patterns and extend them for exercises or projects.
